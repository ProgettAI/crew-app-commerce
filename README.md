## Set up

Start at the Crew Landing Page, https://progettai.ai/crew, then run the Connection Wizard at
https://progettai.ai/crew/connect to generate the `config.json` this app reads.

## Install

- One click from the Kiro Crew App Store, or
- `POST /api/apps/install` on your local Crew gateway with this repository (`https://github.com/progettai/crew-app-commerce`) as the `source`.

After installing, enable the app and restart it after any configuration change.
